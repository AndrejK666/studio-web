# Core-side modules that still name a kit (ADR-0079).
#
# One `from -> to  # why` per line. `from` is a top-level module under src/
# that is not a kit gear, or the crate root (`lib`, `main`). `to` is either
#   - a kit gear folder the module names as `crate::<to>::…` (in the crate
#     root, also a bare `<to>::…`), or whose gear name or REST path
#     (`"studio-documents"`, `"/studio-documents/v1/…"`) is in one of its
#     string literals; or
#   - `kit:<slug>`, a built-in kit's slug as one of its string literals.
# Tests and comments are not read. `assembly/core_kit_tests.rs` fails on a
# pair that is not listed here, and on a listed pair the code no longer has.
#
# This list only shrinks. Do not add a line: contribute through a core port
# instead (MCP tools, Overview blocks, access rules, connector drivers,
# background work, cost metering). When you remove a reference, remove its line.
