# Kits that read or claim another kit's gear without requiring that kit
# (ADR-0071 §5, ADR-0079 §5).
#
# One `kit -> other-kit  # reason` per line. `requires_reads_tests.rs` fails
# on an undeclared pair that is not listed here, and on a listed pair that is
# declared or no longer read, so this list only shrinks.
#
# Do not add a line for a real dependency: add the kit to `requires`. A line
# stays where a `requires` would be wrong today (a cycle, a kit an
# organization may remove, a read that only enriches), until the read moves
# to the model's `/query` (ADR-0079). When you remove a read, remove its line.
