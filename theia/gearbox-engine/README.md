# Gearbox engine

The `gearbox` executable behind the gear catalogue, products and `.gdl`
(gearbox-studio), at the revision `theia/Dockerfile` pins for the session
image, packed as the extension a desktop fetches on first start instead of
carrying it in the installer.

Built and published by `.github/workflows/gearbox-engine.yml`; packed by
`build_vsix.py`. See `docs/desktop-studio.md`, *The gearbox engine*.
