# The old prototype (archive)

This is the old Studio prototype portal, kept as a reference while its
features move into kits of the FrontX portal in
[`studio-frontend-prototype/`](../studio-frontend-prototype/) (ADR-0069). It is
the prototype's latest version from main, moved here unchanged.

It is **not built, tested, linted or deployed**: no workflow, Dockerfile,
compose file, Helm chart or check script points at this directory. Read it,
do not grow it.

Which screen moved to which kit, and what is still missing, is
[`studio-frontend-prototype/docs/parity.md`](../studio-frontend-prototype/docs/parity.md).
The prototype's own README, as it was, is
[`README.prototype.md`](README.prototype.md).
